P	353		converters
D	Value converters to apply before values are rendered.
D	
D	A value converter is a function that converts a value to another value
D	immediately before the value is rendered (and after the value has been type-checked).
D	The converted value is then rendered by the renderer's hardwired rendering logic.
D	
D	When a converter returns a value of type [Object], [Collection], [Map], or [Pair],
D	converters are recursively applied to the returned value's components (object properties,
D	list elements, etc.).
D	
D	At most one converter is applied per value.
D	If multiple converters are applicable, a winner is chosen as follows:
D	- A converter with [String] key wins over a converter with [Class] key.
D	- Between multiple [String] key converters, the converter defined earlier
D	  (according to the mapping's definition order) wins.
D	- Between multiple [Class] key converters, the most specific class (according to class
D	  hierarchy) wins.
D	
D	A converter's key specifies which values the converter should be applied to.
D	A converter with [Class] key is applied to values of that class, including values of its
D	subclasses.
D	A converter with [String] key is applied to values whose path matches the *path spec*
D	described by the string.
D	
D	Path specs can have the following components:
D	- `^` matches the top-level value passed to `renderDocument()` or `renderValue()` (often the
D	   module object)
D	- `pigeon` matches property `pigeon` at any hierarchy level
D	- `[pigeon]` matches map(ping) entry with String key `"pigeon"` at any hierarchy level
D	- `*` matches any property
D	- `[*]` matches any list(ing) element or map(ping) entry
D	
D	Here are some examples of valid property paths:
D	- `"server"`
D	- `"server.timeout"`
D	- `"^server.timeout"` (matches `server.timeout`, but not `racks[12345].server.timeout`)
D	- `"racks[12345].server"`
D	- `"racks[*].server`
D	
D	Paths are matched against path specs component-wise in reverse order.
D	For example, paths `server.timeout` and `racks[*].server.timeout`
D	both match path spec `server.timeout`, whereas path `server.timeout.millis` does not.

C	2985	external	IntSeq		Any
D	A finite arithmetic sequence of integers.
D	
D	A sequence has a [start], [end], and [step].
D	It is either ascending ([step] > 0) or descending ([step] < 0).
D	The default [step] is 1.
D	
D	The members of a sequence are defined as:
D	
D	- seq(0) = [start] + 0 * [step]
D	- seq(1) = [start] + 1 * [step]
D	- seq(2) = [start] + 2 * [step]
D	- etc. where seq(n) <= [end] if [step] > 0, and seq(n) >= [end] if [step] < 0
D	
D	## Construction
D	
D	To construct a sequence, use method [IntSeq()]:
D	```
D	ascending = IntSeq(2, 5)
D	empty = IntSeq(5, 2)
D	```
D	
D	To set a step other than 1, use method [step()]:
D	```
D	descending = IntSeq(5, 2).step(-2)
D	```
D	
D	## Iteration
D	
D	To iterate over a sequence, use method [map()]:
D	```
D	numbers = IntSeq(2, 5).map((n) -> n * 2)
D	```
D	
D	A sequence can also be iterated over in a *for-generator*:
D	```
D	numbers {
D	  for (n in IntSeq(2, 5)) {
D	    n * 2
D	  }
D	}
D	```
D	
D	## Equality
D	
D	Two sequences are equal if and only if they contain the same members in the same order.
D	
D	Facts:
D	```
D	IntSeq(2, 5) == IntSeq(2, 5)
D	IntSeq(2, -3) == IntSeq(2, -2) // both empty
D	IntSeq(2, 5).step(2) == IntSeq(2, 4).step(2)
D	```
